# SmartMetro

A clean, practical, and responsive **Smart Metro Ticketing & Route Planner** frontend project built with React, Tailwind CSS, Lucide Icons, and React Router.

## Features

- 🎟 **Metro Ticket Booking**: Book single, return, or group travel passes with QR codes.
- 💳 **Virtual Metro Card**: NFC pass simulation, instant recharge, and balance management.
- 🗺 **Route & Journey Planner**: Interactive line map with station interchanges, fares, and journey timings.
- 🚉 **Live Station Departure Boards**: Departure schedules and platform information.
- 📱 **Responsive Design**: Designed with a clean, simple, student-friendly UI layout.

## Tech Stack

- **React 18**
- **Tailwind CSS**
- **React Router 6**
- **Lucide Icons**
- **Vite**

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/srrahulchauhan/SmartMetro.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
